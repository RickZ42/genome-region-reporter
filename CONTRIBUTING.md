# Contributing

1. Open an issue with one small task and an observable completion criterion.
2. Create a branch such as `feat/plot-labels` or `fix/empty-input`.
3. Add or update tests when behaviour changes. Use tiny, hand-checkable fixtures.
4. Run the checks in the README, then open a pull request linked to the issue.
5. Ask another group member to review the changes before merging.

Keep all scientific examples synthetic or appropriately licensed. State coordinate
conventions and the meaning of each statistic. Positional overlap alone is not
evidence of regulatory function or a structural-variant mechanism.

The initial implementation includes input validation, basic analysis, plotting,
packaging and CI. Team members should review and understand it, choose meaningful
extensions, and follow the course's guidance on acknowledging coding assistance.
